# 스팀 최신 게임 비교 도우미

## 무엇을 하나

Steam에 최근 나온 게임 가운데 살 게임을 고르려는 사람을 위한 비교 화면입니다. 예산(원) · 최소 별점 · 무료 제외 조건으로 목록을 거르고 가격순으로 정렬할 수 있습니다.
[이 조건으로 추천받기]를 누르면 조건에 맞는 후보 가운데 AI가 한 개를 골라 이유 두 줄과 함께 보여 줍니다. 각 카드의 "원래 화면 보기"를 누르면 Steam 상점 화면이 새 창으로 열립니다.

## 배포 주소

https://stmcrwt.vercel.app

## 데이터

| 항목 | 내용 |
| --- | --- |
| 출처 | Steam 검색 목록 `https://store.steampowered.com/search/?sort_by=Released_DESC&os=win` (출시일 최신순 · Windows), 1~3페이지 |
| 수집 시점 | 2026-09-28 (`data/data.json` 의 `scraped_at` 10:20:36 ~ 10:20:38) |
| 행 수 | 50행 → 49행 (price 칸이 빈 행 1건 제외: 행 22 Solitaire Together) |
| 정제한 열 | `price` : ₩ 와 쉼표를 뗀 정수, 무료는 "무료" 글씨 그대로 · `discount` : -15% → 0.15 비율 · `release_date` : 2026년 9월 27일 → 2026.09.27 · `name` : 앞뒤 공백 정리 |

- 못 바꾼 값은 채우지 않고 NaN으로 두는 규칙이었고, 이번에 해당한 값은 0건입니다.
- 화면에서 쓰는 `data/data.json` 에는 `name` · `price` · `release_date` · `scraped_at` · `detail_url` 다섯 열만 들어갑니다.
- 다시 만드는 순서는 [notes.md](notes.md) 의 「다시 실행하는 순서」에 있습니다.

## AI 추천

- Google Gemini(`gemini-3.5-flash-lite`)를 Vercel 서버 함수 [api/recommend.js](api/recommend.js) 에서 부릅니다.
- **AI에게 넘기는 것** : 화면의 조건 세 개(예산 · 최소 별점 · 무료 제외)와 후보 표입니다. 후보는 화면이 보낸 목록을 믿지 않고 서버가 `data/data.json` 에서 직접 고릅니다. 조건에 맞는 게임을 가격 낮은 순으로 세워 최대 5개를 고르고, 게임마다 `name` · `price` · `release_date` 만 넘깁니다. 후보가 0개면 AI를 부르지 않습니다.
- **AI에게 받는 것** : 고른 게임 이름 `name` 하나와 이유 `reasons` 두 줄이 든 JSON입니다.
- **지키게 한 규칙**
  - 후보 가운데 정확히 하나를 고르고, 이름은 글자 하나 바꾸지 않고 그대로 적는다. 답 형식에서도 `name` 은 후보 이름 중 하나로만 받는다.
  - 이유는 정확히 두 줄로, 각 줄은 공백을 포함해 40자 이내의 한 문장으로 쓴다.
  - 이유에는 후보 표의 `price` · `release_date` 값만 쓴다. 표에 없는 정보(장르 · 평가 · 인기 · 품질 · 할인 등)는 말하지 않는다.
  - 고르는 기준은 ① 가격이 낮은 것(무료는 0원) ② 같으면 표에서 앞에 있는 것 순이다. 같은 조건이면 같은 답이 나오도록 temperature를 0으로 둔다.
  - 대화를 Google 서버에 저장하지 않는다(`store: false`).
- 받은 이름이 후보에 없거나 이유가 두 줄이 아니면 추천을 보여 주지 않고 "추천을 확인하지 못했습니다"를 띄웁니다. 응답이 실패하거나 20초를 넘기면 "잠시 뒤 다시 눌러 주세요"를 띄웁니다.
- 열쇠는 Vercel 환경변수 `GEMINI_API_KEY` 에 넣습니다. 서버 함수 안에서만 읽고 화면으로는 내보내지 않으며, `.env` 파일은 `.gitignore` 로 저장소에서 뺍니다.

## 확인한 것

- **조건 필터 (M10)** : [적용]을 누르지 않아도 칸 값이 바뀌면 바로 적용됩니다. 예산 20000 → 48개 · 15000 → 48개 · 10000 → 43개로, 확인표의 개수와 같았습니다.
- **AI 추천 검증 (M14)** : 정상(예산 15000 · 무료 제외, 후보 24개 중 5개를 넘김)과 후보 최소(예산 2250 · 무료 제외, 4개) 두 경우 모두 추천 이름이 후보 안에 있었습니다. 이유 속 숫자(2250원 · 2026.09.27)도 `data.json` 값과 같았고 지어낸 말은 없었습니다. 후보가 없는 경우(예산 2000 · 무료 제외)에는 AI를 부르지 않고 안내 문장만 보여 줍니다.

## 한계

- **별점 조건은 사실상 쓸 수 없습니다.** 최근에 나온 게임이라 평가가 거의 없습니다. 원본 50행 가운데 `rating_raw` 가 빈칸인 행이 48개입니다. `data/data.json` 에는 별점 열이 없어서, 최소 별점을 고르면 맞는 게임이 0개가 됩니다.
- **목록 1~3페이지만 모았습니다.** 그래서 49개뿐이고, 출시일도 2026.09.25 · 09.26 · 09.27 사흘뿐입니다.
- **AI 추천은 Gemini 무료 사용 한도 안에서 돌아갑니다.** 한도를 넘기면(429) 추천 대신 "잠시 뒤 다시 눌러 주세요"가 뜹니다.
